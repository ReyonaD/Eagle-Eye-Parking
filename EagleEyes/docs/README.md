# 🦅 EagleEye Parking Documentation

Welcome to the central documentation hub for the EagleEye real-time parking application. This directory contains all formal requirements, design specifications, and project management artifacts required for the UNT CSCE Capstone.

## 📊 **Project Tracking & Design**

[Trello Board](https://trello.com/b/IFMGacCF): We use Trello to manage our Sprint Backlog, active tasks, and bug tracking.\
[Figma Prototype](https://www.figma.com/design/ftmfOUMH1ZVUxEmOKf4XoK/EagleEyes-App?node-id=0-1&t=0swajFja7mmvvWPR-1): Interactive high-fidelity mockups and UI components.
